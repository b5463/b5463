# Alexander Jakub Moravčík

I build physical products and self-hosted software. Most of my projects start with a problem I want solved, then grow into hardware, a control panel, or both.

## What I'm building

### [KINO D4](https://github.com/b5463/kino-d4)

A four-lens digital camera for synchronized photographs and short, real-parallax wiggles. The repository holds the hardware build records, wire protocol, USB workbench, simulator, and software used around the camera.

### [SYSTEMS.](https://github.com/b5463/systems)

A self-hosted deployment engine: drop in a zip and get a Docker-backed HTTPS subdomain. It includes deployment controls, logs, health checks, rollback, backups, and a small admin-only dashboard.

## I work with

TypeScript, React, Vue, Node.js, Fastify, PostgreSQL, Docker, ESP32, Web Serial, and the unglamorous parts that make the finished thing maintainable.

I care about keeping original files safe, making hardware repairable, and writing status screens that say what the machine is actually doing.
